# 一键安装提示词 + 操作介绍（新电脑 · 豆包 Work）

## 一、使用方法

1. 新电脑准备：Python 3.9+（安装时勾选 "Add to PATH"）。获取方式为 git clone，需先装 git（提示词会自动检查并安装）；
2. 把下面「提示词」整段复制，发给豆包 Work 的 agent；
3. agent 会自动完成获取、配置、自检并汇报结果；
4. 安装完成后，打开项目文件夹，直接发图即可使用。

## 三、操作介绍（安装完成后怎么用）

**一句话**：打开项目文件夹 → 直接发一张图 → 收到 透明PNG + PSD 两个文件 → 产物自动存到 `output/时间戳/`。

| 环节 | 说明 |
|---|---|
| 安装 | git clone（GitHub 首选；连不上则 Gitee 镜像 `https://gitee.com/image-matting-skill/image-matting-skill.git` 国内免代理；都失败则联系管理员索取压缩包源文件）。随后运行 `scripts/setup.ps1`（建目录、装依赖） |
| 依赖 | 豆包 Work 内置 MediaKit 抠图能力（无需额外安装）；本地仅需 Python + psd-tools（PSD 兜底） |
| 使用 | 对话窗直接发图（无需任何文字），agent 自动执行：存原图 → 清晰化（seedream 4K 高清重绘优先，自检通过省超分；不过回退超分+锐化）→ 抠图 → 生成 PSD → 交付 → 归档 |
| 交付 | 每次同时给 `原图名_cutout.png`（AI 高清清晰化透明底）和 `原图名_cutout.psd`（PS 可打开，三层：原图/透明主体/蒙版） |
| 归档 | `output/YYYYMMDD_HHMMSS/` 内放这批图的 PNG+PSD（同一批图共用一个文件夹），不覆盖 |
| 换设备 | 任何新电脑重复「一、使用方法」即可，项目本身通过 GitHub 同步 |

**注意**：本项目面向「支持多模态 + 具备图像抠图能力」的 agent（豆包 Work 已实测可用）。不带抠图能力的 agent（如普通编码 agent）无法执行核心抠图步骤。

## 四、GitHub ↔ Gitee 双远程同步

- Gitee 的「从 GitHub 导入」是一次性快照，**不会自动同步** GitHub 后续更新。
- 推荐做法（本机已配好两个远程 origin=GitHub、gitee=Gitee）：
  ```powershell
  git push origin main   # 推 GitHub
  git push gitee main    # 推 Gitee（首次会弹登录框：用户名 image-matting-skill + 密码/私人令牌）
  ```
- 或启用 Gitee「管理 → 仓库镜像管理」从 GitHub 定时同步（需 GitHub 账号令牌）。
