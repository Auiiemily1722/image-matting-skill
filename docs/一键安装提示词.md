# 一键安装提示词 + 操作介绍（新电脑 · 豆包 Work）

## 一、使用方法

1. 新电脑准备：Python 3.9+（安装时勾选 "Add to PATH"）。git 非必需——提示词会自动处理（没装 git 则用 ZIP 方式）；
2. 把下面「提示词」整段复制，发给豆包 Work 的 agent；
3. agent 会自动完成获取、配置、自检并汇报结果；
4. 安装完成后，打开项目文件夹，直接发图即可使用。

## 二、提示词（复制整段发给豆包 Work）

```
请在我的电脑上完成「抠图技能项目」的一键安装与初始化。项目托管在 GitHub：https://github.com/Auiiemily1722/image-matting-skill.git

按以下步骤执行，每步都要检查结果：

0. 检查 git 是否可用：
   git --version
   - 已安装 → 继续第 1 步；
   - 未安装 → 优先用 winget 一键安装：winget install Git.Git，装完重开终端后继续第 1 步；
   - 无法安装 git → 改用 ZIP 方式（跳过第 1 步）：
     Invoke-WebRequest -Uri "https://github.com/Auiiemily1722/image-matting-skill/archive/refs/heads/main.zip" -OutFile "$env:USERPROFILE\Desktop\image-matting-skill.zip"
     Expand-Archive "$env:USERPROFILE\Desktop\image-matting-skill.zip" -DestinationPath "$env:USERPROFILE\Desktop"
     解压后目录名为 image-matting-skill-main，将其重命名为 image-matting-skill，然后直接进入第 2 步。
     注意：ZIP 方式以后无法 git pull 更新，更新需重新下载覆盖（git 方式不受影响）。

1. （git 方式）克隆仓库到桌面（或用户指定的目录）：
   git clone https://github.com/Auiiemily1722/image-matting-skill.git
   - 若连接 github.com 失败（网络被重置/超时），检查系统代理：常见的本地代理地址为 http://127.0.0.1:7897 或 7890，用 git config http.proxy <代理地址> 配置后重试；若用户有代理/VPN 需手动开启，提示用户开启后再试。不得绕过失败假装成功。

2. 进入项目目录并运行一键配置：
   cd image-matting-skill
   .\scripts\setup.ps1
   - 脚本会自动创建 input/ 与 output/ 目录、创建 Python 虚拟环境 .venv、安装 psd-tools（PSD 兜底脚本依赖）。
   - 若提示未检测到 Python：请用户先安装 Python 3.9+（勾选 Add to PATH），完成后重跑本步。

3. 自检并理解项目：
   - 完整阅读项目根目录 AGENTS.md（唯一入口），确认理解：项目定位、必读清单、触发规则（发图即触发，无需文字）、执行步骤、硬性规则、目录结构；
   - 阅读 skill/SKILL.md 第 2 步：在豆包 Work 环境中，抠图使用内置 MediaKit 云端能力 `mediakit-cli image remove-image-background`，返回的透明 PNG 下载 URL 有效期 24 小时须立即下载。

4. 汇报结果：
   - 克隆与配置是否成功（附 git 提交号）；
   - 目录结构是否完整（AGENTS.md / skill / config / docs / scripts / input / output）；
   - 明确告知用户：项目已就绪，打开该文件夹直接发图片即可触发抠图，会同时交付 PNG + PSD 并归档到 output/时间戳/。

注意：本项目是给「具备图像抠图能力的多模态 agent」的操作指南，不内置抠图引擎；若宿主 agent 无抠图能力，须明确说明不可用，不假装完成。
```

## 三、操作介绍（安装完成后怎么用）

**一句话**：打开项目文件夹 → 直接发一张图 → 收到 透明PNG + PSD 两个文件 → 产物自动存到 `output/时间戳/`。

| 环节 | 说明 |
|---|---|
| 安装 | 方式一：git clone；方式二（无 git）：GitHub ZIP 下载解压。随后运行 `scripts/setup.ps1`（建目录、装依赖） |
| 依赖 | 豆包 Work 内置 MediaKit 抠图能力（无需额外安装）；本地仅需 Python + psd-tools（PSD 兜底） |
| 使用 | 对话窗直接发图（无需任何文字），agent 自动执行：存原图 → 抠图 → 生成 PSD → 交付 → 归档 |
| 交付 | 每次同时给 `原图名_cutout.png`（透明底）和 `原图名_cutout.psd`（PS 可打开，三层：原图/透明主体/蒙版） |
| 归档 | `output/YYYYMMDD_HHMMSS/` 内放这两份文件，每次任务独立文件夹，不覆盖 |
| 换设备 | 任何新电脑重复「一、使用方法」即可，项目本身通过 GitHub 同步 |

**注意**：本项目面向「支持多模态 + 具备图像抠图能力」的 agent（豆包 Work 已实测可用）。不带抠图能力的 agent（如普通编码 agent）无法执行核心抠图步骤。
