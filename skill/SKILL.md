# 抠图技能（image-matting）

## 触发条件

- 用户在本项目对话窗**直接发送一张图片**，且未指定其他任务 → 立即执行本技能，无需额外上下文。
- 用户文字中包含"抠图 / 去背景 / 去底色 / 分离背景 / 透明底"等关键词 → 执行本技能。
- 可调配置见项目根目录 `config/skill.config.json`（本技能被安装到技能根目录后，配置仍以项目根 `config/skill.config.json` 为准，路径由 AGENTS.md 必读清单指引）。
- **执行边界**：本技能只调用宿主自身能力与项目现成脚本（`skill/scripts/` 下已有文件），**禁止为任务编写或修改任何脚本 / 项目文件**；需要改动项目本体时，由项目所有者另行处理。

## 输入

- 一张图片（PNG / JPG / JPEG / WEBP / BMP 等常见格式）。
- 多张图片 → 每张独立走完下述完整流程；**同一批任务共用一个 `output/时间戳/` 文件夹**（文件名 `原图名_cutout.*` 区分）。

## 工作流

### 第 1 步：原图存档（含大图预处理）
- 把用户发送的图片保存到项目 `input/` 目录，文件名保留原名；重名时追加时间戳后缀（如 `photo_20261014_153000.jpg`）。
- **大图预处理（防"图片太大"）**：原图 >10MB 或长边 >4096 时，先用宿主 `mediakit-cli image resize-image` 把长边压到 2048 再存入 `input/`（各环节存在输入尺寸/体积上限，详见故障排查）。

### 第 2 步：清晰化（对原图；配置见 `config/skill.config.json` → `enhance`）
- 用户反馈直接抠图输出偏糊、分辨率低（原图本身多是小图）。因此**先对原图做清晰化，再抠图**。**全图统一执行：① 先超分保字（前置）→ ② seedream 4K 高清重绘（硬性，每张图都必须做）→ ③ RGB 锐化 → ④ 自检**；**自检通过（文字清晰、无乱码/无风格崩坏）→ 直接进入抠图（不再二次超分）**；**自检不过 → 回退「超分 + 线条锐化」保字路线**；锐化脚本最终兜底。**一次只走一条路线（禁止两条都生成后乱选）**。

1. **seedream 4K 高清重绘（硬性，全图必须）**：调用宿主**生图模型**，以**超分图为参考**重绘高清版。**先判内容类别（判定标准，务必按此执行）**：
   - **实体物品/人物**（真实物品照片、人物照片、实物商品——画面主体是有真实体积与材质的实物）→ **不加防刺绣段**，prompt 用**实物保真版**："将参考图放大重绘为4K超高清版本，保持实物/人物原本的造型、颜色与材质质感完全不变（允许真实照片质感与立体光影），仅提升清晰度，线条更锐利，不改变主体形态与构图，背景由后续抠图去除。必须以参考图为唯一基准，输出与参考图视觉完全一致"；
   - **平面印刷内容**（logo/字符/文字/印花图案/徽章/圆章/纹样/印在物品表面的平面卡通图案——主体是印制的平面图案）→ **必须加平面印刷防刺绣段**，再按图型分：
     - **图中有具象主体**（人物、动物/卡通角色、生物、玩偶等**平面图案角色**作为画面主角，如兔子潮牌图、史迪奇图、骷髅女人物图；**一切卡通/动物/玩偶角色一律算主体图**，如 HelloKitty）→ **主体保真版**（防刺绣段 + 保持角色造型）："将参考图放大重绘为4K超高清版本，保持主体（角色）原本的造型与颜色完全不变。参考图是平面压胶印花（热转印胶膜工艺）：所有图案、卡通、logo、字符都是平面压胶，图案是压贴在底材表面的平整胶膜层，与底材为两层分离结构，无厚度、无凸起，整体质感如贴纸、海报般平整。角色身上的衣物图案（印花、卡通、logo、字符）同样是平面压胶贴膜，衣物本身是平涂色块、无织物纹理渲染。必须以参考图为唯一基准，输出与参考图形状、颜色、构图完全一致，仅提升清晰度（更锐利、边缘更干净、小字更清晰），不得新增任何细节、不得改变材质。严禁刺绣、针线、缝线、绣花线、针脚、毛绒、绒面、织物立体纹理、织纹、提花、贴布、织唛、布标、绣边、凸起浮雕、立体压印、立体厚边、3D、照片质感、布料褶皱光影。这是平面压胶印花，不是纺织工艺"；
     - **画面无具象主体**，纯粹是图形设计（文字/字母、Logo、徽章、几何图形、纹样、植物花纹，如树徽章、Logo 合集、TRIBAL、涂鸦文字）→ **印花版**（防刺绣段 + 徽章构图子句）："将参考图放大重绘为4K超高清版本，保持原图的颜色，平面插画效果。参考图是平面压胶印花（热转印胶膜工艺）：所有图案、logo、字符都是平面压胶，图案是压贴在底材表面的平整胶膜层，与底材为两层分离结构，无厚度、无凸起，质感如贴纸、海报般平整。若图案包含圆形徽章、印章、花环、叶饰等构图，其边缘装饰一律是平涂压胶的线条，无任何立体感。必须以参考图为唯一基准，输出与参考图形状、颜色、构图完全一致，仅提升清晰度（更锐利、边缘更干净、小字更清晰），不得新增任何细节、不得改变材质。严禁刺绣、针线、缝线、绣花线、针脚、毛绒、绒面、织物立体纹理、织纹、提花、贴布、织唛、布标、绣边、凸起浮雕、立体压印、立体厚边、3D、照片质感、布料褶皱光影。这是平面压胶印花，不是纺织工艺"；
   - **误判警示**：**一切卡通/动物/玩偶角色图（兔子、史迪奇、HelloKitty、骷髅女等）都是平面印刷内容里的主体图**，**不得**当作"纯色背景+图形"用印花版 prompt（否则角色会被 seedream 画成毛绒/玩偶质感）；只有画面**没有**任何具象角色的纯图形设计才用印花版。
   - **文字锁定法（平面印刷内容必用，v4 实测有效）**：凡画面含真实文字（logo/文字/印花/徽章等），seedream 重绘前先用 OCR/目视提取原图各文字真实拼写（如徽章内 STANDARD/ESTABLISHED/1968/DETROIT），**按位置写进 prompt 并要求"本图文字必须按以下原文重绘，不得改写、不得增减字母"**（文字用中文引号“”标注）；同时用**允许清单**锁定元素（"画面仅含：…，严禁出现参考图中没有的元素"）+ **平面正面描述**（"圆形/徽章区域是平涂油墨色块：无阴影、无高光、无渐变、无立体轮廓、无厚度、无金属/皮质质感、无压印"）。实测效果：徽章文字从脑补乱码（DRIEICON/GLAHZACO）变为全部正确（STANDARD/ESTABLISHED/1968/DETROIT），顶部/底部大装饰消除。**分型口径**：只要不是整件衣服/物品抠背景透明化的情况，图案/卡通/logo/字符/印花一律按平面压胶处理（无立体、无编织/织纹/刺绣/金属/皮质）——材质锚定平面压胶（热转印胶膜），图案与底材两层分离；整件衣服/物品（抠背景透明化）走实物保真版，保持现有设定（不加防刺绣段、允许实物质感）。
   - 豆包 Work 映射：走 `doubao-creative-design` 流程，用 `image_edit` 参考生成（`image_reference_url_list=[超分图]`）；
   - **执行步骤**：
     ① **先超分保字（前置，必须）**：对原图先做一次 `enhance-image --multiple <m>`（`m = min(8, max(2, round(target_long_edge / 原图长边)))`，尺寸校验见下方回退路线），存 `input/原图名_sr.png`——**目的：把模糊小字放大到 seedream 可辨识的尺度，大幅降低 seedream 改写文字的概率**（实测原图 200~300px 时 seedream 对几十像素的小字会脑补改写）；**小字锁死（必须）**：超分必须用保字 standard 版（professional 会重写字符，含文字图禁用）；超分后用 OCR/目视自检小字——出现明显乱码/错字 → 降级锐化兜底或原图；同时**用 OCR/目视提取原图各关键文字的真实拼写，记入「文字锁定清单」**（供 ② seedream 锁定，防脑补改写）；
     ② **seedream 重绘**：以 `_sr.png` 为参考图执行 `image_edit`（图型对应 prompt + **文字锁定法**，见下）→ 下载结果临时存 `input/原图名_seedream_raw.png`（`curl.exe -L -o`，见「下载约定」）；尺寸：按原图比例、目标长边 `enhance.regenerate_target_long_edge`（默认 2048；seedream 实际输出上限约 2048~2100，"4K"为营销叫法）；
     ③ **锐化补强（必须，满足"线条锐利"硬性指标）**：对 `_seedream_raw.png` 做 RGB UnsharpMask（强度 `enhance.post_sharpen_strength` 默认 1.2）→ 存 `input/原图名_enhanced.png`（宿主有锐化能力优先，否则 `python skill/scripts/enhance_cutout.py --input <原图名_seedream_raw.png> --output <input/原图名_enhanced.png> --strength 1.2`；只锐化 RGB、保留 alpha，不改写文字）；
     ④ **自检（必须，清晰度优先）**：重绘后与原图对比（可调用 `mediakit-cli image image-ocr` 或目视）。**交付 seedream 版（不回退）的条件**：主体/大字清晰、内容无崩坏、**材质保持平面（未出现毛绒/玩偶/刺绣/贴布绣/立体/3D/照片质感——角色图出现毛绒/玩偶/刺绣即材质崩坏，必须回退，不得因整体清晰就放行；实体物品/人物类不检查平面性，允许照片质感与立体光影，只检查主体走样/内容崩坏）**、主体未走样、未被画成印花平面。**小字/局部文字乱码不触发回退**（用户口径：清晰度优先，seedream 锐利质感优先于小字保真，交付 seedream 版并在汇报注明"小字区需人工找补"）；仅当**整体内容崩坏、主体走样、材质/风格明显改变（毛绒/玩偶/刺绣/贴布/立体/3D/照片质感）**时才回退到 2 的路线（**seedream 有随机性：检出刺绣/毛绒等材质崩坏时，先用同一张 `_sr.png`、改用「强化版 prompt」重试 1 次 image_edit——强化版 = 对应图型 prompt（平面印刷防刺绣版）末尾追加：“警告：严禁把参考图绘制成刺绣/针绣/绒绣效果。参考图是平面压胶印花/平面插画，图案是压贴在底材表面的平整胶膜层、与底材完全共面。重绘时严格保持参考图的平面特征，绝不允许出现线迹、缝线、绣花线、针脚、绒毛、凸起、贴布、立体浮雕、织物纹理，输出必须与参考图在形状、颜色、质感上完全一致，只是分辨率更高、线条更锐利”——强化版通常可得平面版；重试仍崩坏才回退**）；**轻微文字补全（如 PLANE→PLANET）不算问题**；
   - **seedream 是硬性要求（不得以任何理由跳过）**：任何图不得因"含文字多""该图之前 seedream 失败过""担心改字"等主观理由跳过 seedream——**每次任务、每张图都必须实际调用 seedream 并保存 `_seedream_raw.png`**（该文件存在是"走过 seedream"的唯一凭证）；只有 ④ 自检**真的执行过**、且确实检出"**整体内容崩坏/主体走样/材质风格大变**"时才允许回退到 2（小字乱码不是回退理由），且必须记录回退原因；交付汇报必须写明本图是否走了 seedream（以 `_seedream_raw.png` 为准）以及**所用 prompt 版本（实物保真版/主体保真版/印花版/强化版，并粘贴 prompt 原文）**，未走即违规；执行窗口开工时先核验所读文档中的 prompt 为最新版（防读旧文档导致弱约束）。

2. **回退路线：超分 + 线条锐化（保字）**：仅当 seedream 自检仍不过（**整体内容崩坏/主体走样/材质风格大变**，小字乱码不回退）时使用（不再重绘）——`mediakit-cli image enhance-image --image-url <原图> --multiple <m>`（若第 2 步 ① 已超分且 ④ 自检不过，可直接复用该 `_sr.png` 做锐化，不必重新超分）
   - 倍率 `m = min(8, max(2, round(target_long_edge / 原图长边)))`（`target_long_edge` 默认 2048；standard 上限 8）；若结果尺寸未放大，改用 `--target-width` / `--target-height` 重试（保持宽高比）；
   - **尺寸自检（必须）**：Pillow 校验输出长边已大于原图长边（真放大才算成功）；未放大要重试，不得假装成功；
   - **超分后追加线条锐化**：对超分结果再做一次 RGB UnsharpMask，强度 `enhance.post_sharpen_strength`（默认 1.2）。宿主有锐化能力优先，否则 `python skill/scripts/enhance_cutout.py --input <超分图> --output <input/原图名_enhanced.png> --strength 1.2`（脚本只锐化 RGB、保留 alpha，不透明图同样适用）；
   - **结果自检（必须，防脑补乱字）**：超分对超小/模糊文字也会脑补（实测短裤小字被猜成乱码）——锐化后用 OCR/目视检查：出现明显乱码/错字 → 降级到 4 锐化兜底，或直接原图抠图并在汇报中说明；轻微补全不算；
   - 最终结果存 `input/原图名_enhanced.png`；下载 URL 用 `curl.exe -L -o`。

3. **professional 超分（可选）**：无文字纯图形图可改用 `--tool-version professional`（发丝级，线条纹理更锐利；**会按语义重写个别字符**——实测 `EVERY DAY'S`→`EVERY DAY IS`，含文字图禁用；输入须宽高均 ≥256，不足先 standard 预放大）；同样需尺寸校验。

4. **锐化兜底**：超分不可用 → 直接用原图抠图，抠图完成后运行：

   ```powershell
   python skill/scripts/enhance_cutout.py --input <透明PNG> --output <增强PNG> --strength 1.0
   ```

   只对 RGB 通道做 UnsharpMask 锐化，alpha 通道原样保留、尺寸不变；`--strength` 0.5~2.0。并在汇报中说明"本次仅锐化，未清晰化/未超分"。

### 第 3 步：抠图（核心，调用宿主能力）
- 对**第 2 步的输出图（超分原图或原图）**调用宿主 agent 内置的**图像抠图 / 去背景 / 主体分离**能力，生成透明底 PNG。
- **白色/浅色底预处理（必须判断，白贴白防误抠）**：背景为白色/极浅色、且主体含大面积白色（白手套/眼白/白裙/白色商品等）时，先运行 `python skill/scripts/fill_external_background.py --input <输入图> --output <input/原图名_bgfilled.png>` 把外部背景染成深色，**再以染色图为抠图输入**。脚本从四边 BFS 泛洪找背景连通区，只染面积占比 ≥ `--min-block-ratio`（默认 0.05）的大块，防误染主体触边白块；背景判定容差 `--threshold` 默认 40，背景非纯白（米白/浅灰）时调至 60~80。染色只发生在输入端——主体白色在深色背景（默认深蓝 25,45,95）上对比鲜明，模型不再把主体白误抠成透明；alpha 输出不受影响，无需反色恢复。仍有个别封闭区域（如眼白）被抠漏时，兜底：从边缘泛洪区分外部背景与内部孔洞，只回填透明像素、取原图色（勿直接填纯白，避免误伤浅色皮肤）。
- **深色/黑色单一底色图案稿预处理（必须判断）**：原图背景为单一深色/黑色、图案为浅色/白描（如黑底 T 恤印花稿）时，抠图模型会把黑底误判为主体（实测：黑底被保留成"黑色 T 恤"还脑补出领口标签）。处理：先对输入图做**反色**（`mediakit-cli image invert-image` 或 PIL 反相：黑底→白底、白描→黑描）→ 抠图（白底易识别去除）→ **再反色恢复**（图案配色还原，背景保持透明）。彩色元素（如红玫瑰）反色后为补色，二次反色后完全复原，可放心使用。
- **豆包 Work 环境映射（已验证可用）**：`mediakit-cli image remove-image-background --image-url <超分原图或原图> --scene <general|human|product>`
  - `human`=真人人像；`product`=商品主体；`general`=通用（动漫/二次元、商标/Logo、不确定主体，或前两者效果不佳时改用）；
  - 返回透明 PNG 下载 URL（**有效期 24 小时，须立即下载**），默认输出与输入同尺寸（即 ≥ 原图）；
  - 若模型输出尺寸与输入不一致，须缩放对齐到输入尺寸（build_psd.py 会自动告警并对齐）。
- **下载约定**：所有云端结果 URL 一律用 `curl.exe -L -o "<保存路径>" "<URL>"` 下载。**注意：豆包 Work 终端对"从 URL 下载文件到本地"这一动作会统一弹出权限确认窗（仅「拒绝/允许一次」），与命令写法无关——Invoke-WebRequest / 裸 curl / curl.exe 三种写法都会弹，无法靠改命令绕开，属正常流程**。执行窗口做法：看到弹窗直接继续下载（用户会点"允许一次"），**不得因弹窗中断流程、不得反复询问或解释弹窗**；开工汇报先写明"本次预计 N 次下载确认（每张图 2 次：超分图 + seedream 图），请连续点允许"；同一 URL 不得重复下载。
- 质量要求：
  - 输出尺寸与抠图输入尺寸**一致**（≥ 原图尺寸）；
  - 主体边缘干净，发丝、半透明物（玻璃、纱等）尽量保留；
  - 背景完全透明（alpha=0），不残留白边 / 色边。

### 第 4 步：生成 PSD
- 优先：宿主 agent 有原生 PSD / PS 兼容文件生成能力 → 生成三层 PSD（原图 / 透明主体 / 蒙版参考），原图层用第 2 步的超分原图。
- 兜底：运行脚本（脚本与 SKILL.md 同级目录）：

  ```powershell
  python skill/scripts/build_psd.py --original <超分原图或原图> --cutout <透明PNG> --output <output/时间戳/原图名_cutout.psd>
  ```

  脚本生成三层（**图层名用英文** Original / Cutout / Mask Reference，保证 Photoshop 等软件跨平台显示兼容）：①原图 ②透明底抠图主体 ③抠图蒙版参考（白=保留 / 黑=去除，取自 PNG 的 alpha 通道）。
  抠图尺寸与输入不一致时，脚本自动缩放对齐并在 stderr 告警。

### 第 5 步：对话框交付
- **必须同时**交付两个文件：`原图名_cutout.png`（超分高清版）+ `原图名_cutout.psd`（使用宿主文件交付机制，如 present_files）。
- 交付文件与归档文件为同一份：先归档到 `output/` 再交付，或交付后立即同步归档，保证两边一致。

### 第 6 步：归档
- 在 `output/` 下新建文件夹，命名 `YYYYMMDD_HHMMSS`（本地时间、24 小时制，如 `20261014_153000`）。
- **同一批任务（一次发送的多张图）共用一个文件夹**：文件夹内按 `原图名_cutout.png` / `原图名_cutout.psd` 区分各图。
- 同一秒内多批任务 → 文件夹名追加 `_1`、`_2`… 防重。

## 多图与异常

- 多张图：按收到顺序**逐张串行**执行完整流程（一张完整走完、交付并归档后再处理下一张）；**同一批任务的产物共用一个 `output/时间戳/` 文件夹**（靠 `原图名_cutout.*` 文件名区分），各自交付。
- agent 无抠图能力：明确说明无法执行，不生成假产物。
- 尺寸不一致：PSD 脚本自动缩放对齐并告警；PNG 应保证与抠图输入尺寸一致（≥ 原图）。
- 任一环节失败：保留 `input/` 原图，向用户说明失败环节与原因。
